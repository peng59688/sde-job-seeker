# Job Seeker（分享版）

一个静态、可分享的求职岗位看板：内置目标公司与在招岗位快照，上传你的简历即可在浏览器本地算出每个岗位的匹配度。

## 怎么用（给朋友的 3 步）

1. 打开分享链接（或下面"本地运行"）。
2. 点击 **"上传简历算匹配度"**，选择你的简历（PDF / DOCX）。
3. 浏览公司卡片：每个卡片列出该公司在招岗位，**岗位标题就是投递链接**，点进去直接投递。
   - 匹配度 ≥80% 标"非常适合投递"；60–79%"建议投递"；<60%"自行判断"（不置灰，仅供参考）。
   - 可用筛选器按目标级别、领域标签、最低匹配度、地点（西雅图 / Remote）过滤。

## 匹配度怎么算

- 页面内置 194 个通用技术词表和每个岗位从完整 JD 提取的关键词（绝大多数岗位已获取完整 JD；少数只有公司招聘首页、拿不到 JD 文本的岗位会显示"JD 未获取，仅标题参考"）。
- 你的简历用同一词表在**浏览器本地**提取技能词，匹配度 = JD 技能关键词中被简历覆盖的比例（catch ÷ (catch + miss)，JD 中心口径），并列出已覆盖词（绿色 chips）与缺失词（橙色 chips；缺失词按岗位标题相关度与 JD 出现顺序排序，默认展示前 8 个，可展开看全部）。JD 技能词少于 5 个的岗位会打"样本少、仅供参考"徽章。
- 目标级别（Entry / Mid-level / Senior / Staff+）可手动选择，也可按简历经历粗估；级别只影响推荐排序，不会隐藏其他岗位。

## 隐私说明

- 简历只在**你自己的浏览器里**解析（PDF.js / Mammoth.js），不会上传到任何服务器；刷新页面后即清除。
- 勾选/收藏状态只存在浏览器 localStorage，别人看不到你的操作。

## 本地运行

```bash
# 方式一：直接双击打开 index.html

# 方式二：本地起一个静态服务（推荐，避免浏览器文件协议限制）
cd sde-job-seeker
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

需要联网（简历解析库走 CDN）。

## 数据说明（每日自动更新）

- 岗位快照由 GitHub Actions **每天早上自动刷新**（`.github/workflows/refresh.yml`，约 09:00 PT），页面打开时会自动拉取最新快照，也可点页面顶部的"⟳ 刷新"按钮手动更新。
- 数据来源：57 家公司的公开招聘 API（Greenhouse / Lever / Ashby），只收录后端 / SWE 相关 title、Remote 或西雅图地区的岗位；每个岗位的 JD 关键词用同一套 194 词词表从完整 JD 文本提取。
- 另有 24 家公司没有公开招聘 API（如 Apple、DoorDash、Salesforce 等），其岗位沿用上次人工核实的数据并在数据中标记。
- 当前快照日期与岗位数显示在页面顶部；TC 均为估算值；标注"招聘动态待确认"的公司信息尚未核实。
- 排序默认：综合分（TC 中位数 + WLB 加权）降序；上传简历后可按匹配度重排。
- 岗位链接指向各公司官方招聘页（Greenhouse / Ashby / Lever / 官网），均为发布时核实过的地址。

## 技术

纯静态页面：HTML + JS + CDN，无后端、无构建步骤。岗位数据放在 `data/*.json`，由 `scripts/refresh_jobs.py` 每日生成（GitHub Actions 定时跑）；`index.html` 内仍保留一份内嵌快照做降级（双击本地打开也能用），"下载单文件 HTML"会把当前最新数据一起打包进去。
